Velaire — Multi-page demo website

This repository contains a simple multi-page website for a fictional fashion house named "Velaire".

Files added
- index.html (home)
- products.html
- trustees.html (Board of Trustees)
- events.html (upcoming events)
- inquiries.html (inquiries & appointment booking)
- about.html
- css/style.css (external stylesheet)
- js/script.js (shared JavaScript features)
- dom-structure.html (DOM structure outline)

How to run
1. Serve the repository directory using any static server. Example using Python 3:
   python -m http.server 8000
2. Open http://localhost:8000 in a browser.

Notes
- The site uses client-side storage (localStorage) for inquiries and appointments (demo only).
- Images use placeholder URLs (via.placeholder.com). Replace with real assets in /images if desired.
